## 外汇（FX）到底在做什么

游戏里你要学的就是这套东西。**规则和真实市场一致。**

### 1. 你在买卖"汇率"，不是股票
`USD/JPY = 110.20` 意思是 1 美元 = 110.20 日元。

- **做多（买入）**：赌汇率上涨
- **做空（卖出）**：赌汇率下跌（先借来卖，便宜了再买回，赚差价）

盈虧 = （平仓价 − 建仓价）× 方向 × 通貨量

### 2. 点（pips）与手数
| 概念 | 说明 |
|---|---|
| 1 pip | 日元对汇率的最小刻度，通常是 **0.01 円** |
| 1 万通貨 | 1 pip 波动 = **100 円** |
| 10 万通貨 | 1 pip 波动 = **1000 円** |
| 点差（Spread） | 买价与卖价的差。**开仓瞬间你的账面就是负的**，这是交易成本 |

### 3. 杠杆（レバレッジ）—— 最危险的发明
```
必要保证金 = 通貨量 × 汇率 ÷ 杠杆
```
- 10 万本金 + 10 倍杠杆 → 能持有 100 万日元的仓位
- 汇率动 1%，仓位盈亏 1 万日元：**等于你本金的 10%**
- 100 倍杠杆下，汇率只要动 **0.5%** 就爆仓（外汇里这是几分钟的事）

游戏里杠杆可在 **1× ~ 100×** 之间无级调节，实时显示"爆仓价距离"。

### 4. 维持率（維持率）—— 游戏里最重要的一个数字
```
净值   = 账户现金 + 所有持仓的浮动盈亏
维持率 = 净值 ÷ 必要保证金 × 100%
```

| 维持率 | 发生什么 |
|---|---|
| **100%** | **追証**（追加保证金通知），要求你补钱 |
| **50%** | **强制平仓（ロスカット）**，券商不问你的意见直接砍仓 |

> ⚠️ 关键细节：维持率用的是**账户全部净值**。所以
> · 同一个账户里其它品种的浮亏也会把你推下悬崖
> · 闲置现金会缓冲爆仓——**"钱多反而爆得慢"**
> · 这正是为什么**借钱加仓的人死得特别快**：一爆，保证金和借来的钱一起没

### 5. 隔夜利息（スワップ）
持仓过夜产生的两国利率差。买高息货币能收钱，周三通常三倍，周末不计息。

游戏里南非兰特/日元（ZAR/JPY）就是高息品种——**能吃到惊人利息，也能一口气全吐回去。**

### 6. 止损 / 止盈
在预设价位自动平仓。**这是散户唯一真正有效的风控。**

难点从来不是"设置"，而是"到了之后真的按下去"。游戏会在教程里专门讲这个心理机制。

## 借贷系统

四种渠道，利率越高越容易借到：

| 渠道 | 年利 | 特点 |
|---|---|---|
| 友人からの借金 | 0% | 不要利息，但要脸。还不上会失去朋友 |
| 消費者金融 | 18% | 最快到手，也最快开始追着你跑 |
| 闇金融 | 36.5% | 多少都借得到。代价是你的冷静值 |
| **小金萌智子・個人間融資** | **109%** | 个人间融资的法定最高利率。只借给正在走向毁灭的人 |

**利息按日复利累积**（与真实券商一致）：
- 年利 109% 借 100 万 → 一年后 **296.9 万**
- 换算成日息约 **0.3%**：30 天吃掉 9%，100 天吃掉 34.7%

借钱会**降低冷静值、提高贪欲**。冷静值低于 40 会解锁闇金融——**而那正是最不该借钱的时候。**

> 最致命的组合是 **借钱 + 高杠杆 = 双重爆仓**。
> 市场把你的保证金打爆，你的债**不会**跟着消失。
> 芽吹就是这么消失的：她不是输光了钱，是输光钱之后还欠着钱。

## AI 交易员「ゆき」（v1.1 新增）

在「人物」页最下方，你可以让**第四个参赛者**下场——一个由你自己接的 AI 模型驱动的对手。

### 她是什么
原作里芽吹提议办了一场四人 FX 竞赛。游戏里，久留美、芽吹之外的第三个对手「ゆき」由真实的大模型扮演：
她会读行情、算维持率、开平仓、选择杠杆，也会对你说风凉话。

她**不是假的**——她的每一笔交易都落在独立的账户上，有真实的持仓、真实的爆仓、真实的负债。
她会因为杠杆开太大而爆仓，也会连续几轮什么都不做，只在旁边看你。

### 三种奖励机制

#### 1️⃣ 三人 FX 竞赛
每 **7 天**结算一次，按**净值增长率**排名：

| 名次 | 奖励 |
|---|---|
| 第 1 名 | **+3 洞察点** |
| 第 2 名 | +1 洞察点 |
| 垫底 | 没有奖励，但她会记住 |

对手是「ゆき」和**山師芽吹**。芽吹是脚本化的，曲线还原原作：
**前 16 天连胜（这正是久留美觉得市场可以征服、重新下场的理由）→ 之后崩坏 → 爆仓 → 只剩零头。**

#### 2️⃣ 对赌
押「ゆき」本期收益为正：
- 她赚了 → 你收回本金 + 按她的收益率分成（上限 4 倍）
- 她亏了 → **你押的钱全没了**

用的是**钱包里的钱**，输光不影响保证金。这是游戏里最像原作那种"借钱赌一把"的机制。

#### 3️⃣ 挑战目标（你领里程碑奖励）
给她设一个收益目标（比如"7 天 +20%"），让她去挑战：
- 她达成 → **你领里程碑奖励**（洞察点 = 2 + 目标%/25）
- 她失败 → 打击她的信心（后续会触发她心态崩坏的对话）

最多同时挂 3 个。**定太高她会去冒不该冒的险然后爆仓**——这本身就是原作讲的事。

### 洞察点 → 换钱 / 永久技能

洞察点不会被交易亏掉。它有两种用法：

#### 💱 换成现金
**1 点洞察 = 100,000 円**（10 万）

兑换后直接进**钱包**（不自动入金），你可以自己决定什么时候把它转成保证金。

> 设计意图：洞察点来自"赢过 AI"，而把它换成钱，等于把「看穿市场的能力」变现成「继续下注的本金」——这正是久留美会做的事。

#### 🔧 永久技能（6 个）

| 技能 | 效果 | 成本（每级） |
|---|---|---|
| 💴 交易成本减免 | 点差成本 −10%/级（共 3 级） | 3 / 6 / 10 |
| 🛡️ 爆仓保险 | 被强平时返还保证金 10%/级（共 3 级） | 3 / 6 / 10 |
| 📡 情报力 | 新闻提前提示（共 2 级） | 3 / 6 |
| 🏦 **信用力** | **所有借贷渠道额度上限 +25%/级**（共 3 级） | 4 / 8 / 14 |
| 💱 **利息谈判** | **隔夜利息：收入 +30%、支出 −30% / 级**（共 3 级） | 3 / 7 / 12 |
| 🔥 **胆力** | **被强平的精神打击 −40%/级**（共 2 级） | 3 / 6 |

新增的三个技能都直接对应游戏的核心机制：

- **信用力**：让你能借到更多。注意——这只是提高了上限，**利息一分没少**。
- **利息谈判**：高息货币持仓（如做空 ZAR/JPY）的成本大幅下降，让「套息交易」真正可行。
- **胆力**：爆仓不再让你冷静值直接崩盘，能多扛几轮。

技能满级成本：全 6 项约 105 点洞察。

### 怎么配置

「設定」→ **🤖 AI 交易员（接入 API）**

支持任意 **OpenAI 兼容**接口，内置 DeepSeek / OpenAI / Moonshot / 通义千问 预设，也可以手填：

```
接口地址： https://api.deepseek.com/v1/chat/completions
模型名：   deepseek-chat
API Key：  sk-...
```

填好后点「测试连接」确认能通，再保存。她就会登场。

### ⚠️ 使用前必读

1. **Key 只保存在你手机本地**（localStorage），请求**直接发往**你填的地址。
   本游戏不收集、不上传、不中转任何数据。但浏览器直连时 Key 会出现在前端请求里——
   **请用单独的、额度受限的 Key，不要用主账号 Key。**
2. **每次思考都消耗你的 API 额度。** 她约每 1 分钟自主决策一次，可以随时在界面上暂停她。
3. **CORS 限制**：部分服务商不允许浏览器跨域请求，会直接失败。
   这种情况换服务商，或用支持 CORS 的中转地址。
   **APK 版没有这个问题**——APK 用原生层发请求，完全绕过 CORS。
4. 她出错时游戏会**自动暂停她**，避免重复刷请求烧额度。

### 她的行为约束（防止模型乱来）
- 单次最多开 2 笔新仓，总持仓上限 4 笔
- 余额 < 5000 日元时只能平仓
- 杠杆被夹在 1~100，数量被夹在 1000~200 万通貨
- 非法品种 / 非法方向 / 未知动作全部被忽略
- 返回的不是合法 JSON 时记为一次错误，不崩溃
- **并发保护**：她正在思考时不会重复发请求

## 开发过程中被测试抓出的真实 bug

这四个如果没被抓住，游戏打开就是**白屏**：

1. **`#btnPause` 不存在** → `bindHud()` 里绑定了它，初始化直接抛错
2. **`UI.init()` 顺序错误** → 在 `buildScreens()` 之前就去取 `#chart` 画布，拿到 `null`
3. **`$$` 语义混乱** → 64 处当单元素用、11 处当数组用，`forEach` 调用直接崩
4. **屏幕容器没有 id** → `showScreen()` 找不到 `#sc-trade` 等节点，五个页面全部 `opacity:0`（等于整屏空白）

还有两个**设计缺陷**：

5. **爆仓价算错**：原实现假设"只有这一笔仓位"，忽略了账户闲置资金的缓冲作用 → 给玩家虚假的安全感。已改为用真实维持率公式反推，并加入"其它品种浮亏也会拖你下水"的正确行为
6. **默认手数 2 万 × 10 倍**：保证金占初始资金 73%，新手第一次点"买入"就秒爆 → 已改为默认 1 万通貨

## 关于原作的一点背景

作者**でむにゃん**本人就是现实里的散户，漫画里"赌狗心理"的描写完全来自亲身经历——他在连载期间做空白银爆仓，被读者在评论区"赛博追悼"。

所以这部作品有一个残酷的地狱笑话：**"到底是女主先跳，还是作者先跳？"**

而漫画里唯一上岸的角色是**高根やす子**：她在爆仓后接受亏损、彻底离场，把剩下的钱投到自己的作品上，最后成了职业漫画家。

**这就是作者给自己留的救赎，也是这个游戏想传达的唯一一句正经话：**

> 停手这件事，越早越容易，越晚越不可能。
